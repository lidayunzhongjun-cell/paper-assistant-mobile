# 论文精读 · Android

把论文、阅读进度、重点标记、笔记、问答和知识图谱放在同一处。可以先离线阅读，再用自己配置的 AI 服务精读选段或梳理全文。Android App 独立安装，不需要 Zotero。

> 当前版本：**2.1.0 测试版** · Android 8.0 及以上 · 支持 PDF、DOCX、DOC

## 下载与安装

从 [Releases](https://github.com/lidayunzhongjun-cell/paper-assistant-mobile/releases) 下载 `paper-assistant-2.1.0-android.apk`，在 Android 手机上打开安装。若系统提示，请允许当前文件管理器安装应用。安装后可直接导入论文阅读；AI 功能需要在 App 内设置兼容 Chat Completions 的服务。

这是独立签名的测试安装包，尚未上架应用商店。更新时请使用同一签名的安装包；安装前建议先备份重要论文。源码见本仓库及同版本的 `paper-assistant-2.1.0-source.zip`。

## 可以做什么

| 功能 | 使用方式 |
| --- | --- |
| 管理论文 | 导入 PDF、DOCX、DOC；按名称搜索、建立分类，或在“我的论文”删除论文及其相关缓存。 |
| 阅读原文 | PDF 支持翻页、上下滚动、双指缩放和文字版；Word 以适合手机的重排页面阅读。 |
| 精读选段 | 长按选择文字，可用“选择整段”辅助扩展选区，再点底部“精读选段”提问。 |
| 重点与笔记 | 为选中文字添加柔和颜色和笔记，从批注列表返回原文。 |
| 翻译选文 | 选择翻译服务和语言，在阅读页查看译文；已完成的译文按论文缓存。 |
| 全文知识图谱 | 根据原文建立章节、段落、术语与关联大纲；或导入已有的论文总结，在本地建立导航。 |
| 连续问答 | 围绕选段或全文追问，结合图谱定位相关原文；可分别清除问答、段落缓存和全文缓存。 |
| 保存与备份 | 论文和阅读数据按篇保存；可自选存储目录，并将单篇论文及阅读数据导出为 ZIP。 |

## 从一篇论文开始

1. 在首页点 **导入论文**，通过系统文件选择器选择 PDF 或 Word 文件；可一次选择多篇。
2. 打开论文，在 **阅读工具** 中选择翻页或上下滚动。PDF 可切换文字版；双指夹住内容可缩放和平移。
3. 长按原文选择文字。选区难以拉到段落边界时，点 **选择整段**；然后可点 **标记 / 笔记**、**翻译选文** 或 **精读选段**。
4. 使用 AI 前，在首页 **设置** 中填写 API 地址、模型名称和 API Key。只阅读、分类和做本地笔记不需要配置模型。
5. 想梳理全文时，在 **精读问答 → 会话与全文工具 → 全文阅读与缓存管理** 中选择建图方式；完成后到 **知识图谱** 查看章节和段落，并可从节点回到原文。

### 两种建图方式

- **建立全文知识图谱**：从论文提取原文，分批交给已配置的模型整理。它会产生 API 用量；任务可在后台继续，通知栏显示进度。网络或系统中断后可从已保存的批次继续。
- **导入总结建导航 · Word / TXT**：导入已由其他 AI 或自己写好的 DOCX、DOC、TXT 总结，按标题和内容在本地建立章节导航与原文候选索引。这一步不调用模型。总结只是辅助导航；问答仍需以可定位的论文原文为依据。

图谱用于帮助检索和理解全文，不替代原文。复杂版式、公式及模型生成的结论都应回到论文核对。导入总结文件上限为 2 MB，提取文字上限为 12 万字符。

## 翻译、存储与隐私

翻译可选择 MyMemory、DeepL、LibreTranslate、Lara、有道智云、百度翻译、腾讯云或已配置的 AI 模型；不同服务可能要求各自的账号和密钥。只有使用翻译时，所选文字才会发送给选定的翻译服务。服务额度和费用由相应提供方决定。

论文默认保存在 App 私有目录。也可在 **设置 → 选择存储目录并迁移** 中选择空文件夹；App 会建立 `PaperLibrary`，把论文及其阅读数据一起迁移。每篇论文保存原文件及对应的阅读缓存、图谱、问答、标记和笔记。删除论文会删除当前论文库中的这些数据；原始导入文件和手动导出的备份不受影响。

提问时，必要的原文和对话会发送到你配置的模型服务；原文建图会分批发送论文文字。API Key 使用 Android 系统密钥加密保存，不包含在论文备份中。App 不提供自动云同步。右上角 **备份** 可导出当前论文及阅读数据为 ZIP；**当前版本没有 ZIP 一键恢复入口**，请妥善保管原论文。

## 当前限制

- 扫描版 PDF 可以阅读，但不提供整篇 OCR。2.1.0 在检测到选中文字映射明显乱码时，会尝试在设备内对当前选区 OCR；公式和专有名词仍应对照页面核实。
- 双栏、脚注、表格和复杂公式可能影响文字选择或原文定位；Word 的重排阅读页不等于原文件页码。复杂版式建议优先用 PDF。
- 后台建图可能被系统省电策略、网络故障或后台时限中断；已保存的批次可用于继续建图。未返回的模型请求仍可能产生服务端费用。
- 单篇论文导入上限为 60 MB；加密 PDF 需先解密。图表的视觉内容不会被当作可检索文字理解。

## 开发与源码

构建需要 Node.js 24、JDK 17、Android SDK Platform 35 和 Build Tools 35.0.0。在项目目录运行：

```powershell
npm ci
./scripts/setup-sdk.ps1
npm test
./scripts/native-check.ps1
./scripts/build-apk.ps1
node scripts/source-package.mjs
```

构建脚本会在本机 `.signing/` 创建签名材料。请保留它用于后续覆盖安装，**不要提交或公开**签名密钥、API Key、个人论文和缓存。源码包会排除这些本地文件。

项目核心采用 [AGPL-3.0-or-later](LICENSE)；所含第三方组件各自遵循其许可证。Android App 复用 [Paper Assistant Next](https://github.com/lidayunzhongjun-cell/paper-assistant-next) 的部分精读核心，但 Zotero 的 XPI 需单独安装。
