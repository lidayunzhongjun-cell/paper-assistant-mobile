# 论文精读 · Android 1.7.0

独立 Android App，包含本地 PDF / Word 论文库、阅读器和 Paper Assistant Next 2.1.1 的精读核心。无需安装 Zotero；不是在手机运行 XPI，而是复用相同的图谱、检索、对话和缓存清除逻辑。

安装包：`dist/paper-assistant-1.7.0-android.apk`。包名 `org.paperassistant.mobile`，最低 Android 8.0 / API 26，目标 API 35。建议使用更新过的 Android System WebView / Chrome。此包为独立签名的本地测试版本，未上架应用商店。

1.7.0 / versionCode 15：新增 Lara Translate。设置中填写 Access Key ID 和 Access Key Secret，翻译框即可选择 Lara；通过官方 Lara Java SDK 1.12.0 发起签名请求，使用 Standard、忠实风格和 `text/plain`，并强制启用 `noTrace` 隐私模式。支持自动识别或英语、中文、日语、德语、法语互译，译文继续按论文缓存。ID 与 Secret 由 Android 系统密钥加密保存，不进入页面数据或论文备份。SDK 与 Gson 依赖固定版本并验证 SHA-256；没有真实 Lara 账户密钥，未进行在线计费接口实测。

1.6.0 / versionCode 14：新增有道智云文本翻译、百度通用翻译和腾讯云机器翻译。

在“设置 → 翻译服务”展开相应服务，填写 ID 和密钥并保存；回到论文翻译框选择服务。留空保留原有凭据，勾选清除会同时删除该服务的 ID 和密钥。腾讯地域默认 ap-guangzhou，可按账户服务地域修改。密钥和 ID 在 Android 端加密保存，不回传页面、不进入论文备份。长选文自动按 UTF-8 字节分段并间隔发送，译文按服务缓存；错误码提示鉴权、开通状态或额度问题，不自动切换付费服务。

对应官方接口与凭据：
- Lara：Access Key ID＋Access Key Secret，由官方 Java SDK 负责签名与认证；本 App 设置 `noTrace=true`。https://developers.laratranslate.com/docs/translation-api
- 有道智云：应用 ID（appKey）＋应用密钥，v3 SHA-256 签名。https://ai.youdao.com/DOCSIRMA/html/trans/api/wbfy/index.html
- 百度翻译：APP ID＋密钥，MD5 签名。https://api.fanyi.baidu.com/doc/23
- 腾讯云机器翻译：SecretId＋SecretKey，TC3-HMAC-SHA256 签名，TextTranslate API 2018-03-21。https://cloud.tencent.com/document/api/551/15614

三家签名已通过独立 Node crypto 与 Java 实现的交叉校验，并验证返回解析、语言映射及错误处理；没有真实账户密钥，未进行付费服务在线实测。Lara 的鉴权与流式响应由官方 SDK 处理。

## 安装与使用

1. 将 APK 发到 Android 手机，通过系统安装器安装；如系统要求，允许此次所用文件管理器安装应用。
2. 进入“设置”，填写兼容 Chat Completions 的 API 地址、模型和自己的 Key。离线阅读不需要 API。
3. 点击“导入论文”，从系统文件选择器选择 PDF、DOCX 或 DOC，可多选。文件会复制到 App 自己的论文目录，相同内容按 SHA-256 去重，不覆盖已有问答。
4. 打开论文，选择翻页或上下滚动、输入页码，双指或按钮缩放；PDF 还可切换文字版。长按选中文字，可按选区旁“选择整段”协助扩展；点击底部“精读选段”直接解读，或点击“翻译选文”显示可缓存译文。
5. 在“精读问答”展开“全文阅读与缓存管理”，点击“建立全文知识图谱”（也可从图谱页直接建立）。允许通知后可在通知栏看进度、停止任务，期间可以继续阅读或退到后台。模型分批生成高密度大纲，保留章节/小节/段落层级与原文位置、独立术语及跨章节关联，并串联全文核心。
6. 在“知识图谱”展开节点，查看原文、关系和术语，点击具体段落继续追问。后续问答先根据图谱预判原文区域，再读取相关原文生成回答。
7. “清除当前问答记录”位于建图按钮上方，“清除全文缓存”在下方；选段会话显示“清除本段缓存”。清缓存保留问答，清问答保留缓存。段落清除要求唯一匹配；存在重复文本时，从图谱进入指定段落。
8. “设置 → 选择存储目录并迁移”可选择一个手机文件夹，例如 Documents 下新建“论文”。系统选择器授予该目录的持续访问权限；App 在里面建立 PaperLibrary。目标中若已有论文库则不覆盖，请选空目录。后台建图期间不能迁移；目录支持安全重命名才能写入。
9. 右上角“备份”将当前论文及阅读数据一同导出为 ZIP，由系统选择保存位置。

## 数据存放

```text
默认 App 私有 files/，或自选文件夹/
└─ PaperLibrary/
   └─ <原文件内容的 SHA-256>/
      ├─ document.pdf / document.docx / document.doc   原始论文
      ├─ paper.json     标题、导入时间、大小
      ├─ reading.json   原文缓存、页码映射、图谱、术语、问答、收藏、草稿和阅读进度
      ├─ graph-task.json         任务状态、当前阶段、公开模型配置（不含 Key）
      ├─ graph-input.json        建图时的提取原文
      └─ graph-checkpoints.json  已完成模型批次的断点
```

`reading.json` 集中存储本篇论文的各类缓存与问答，避免跨论文混用。缓存清除不删除原始论文。原始导入文件不被修改。默认目录使用临时文件、同步及原子替换。自选目录通过 Android 文档接口写临时文件、保留旧文件备份后重命名，主文件缺失时读取备份恢复；不支持重命名的提供方会报错。损坏记录报错并保留，不静默覆盖。建图成功后清空临时原文与批次响应；全文清除也清除这些断点。后台提交只合并图谱字段，旧版本的阅读进度写入不会覆盖新图谱。

模型设置与论文数据分开保存；API Key 使用 Android Keystore + AES-GCM 加密，不回传给网页界面，也不放入论文备份。论文内容只在用户使用模型功能时发送至用户配置的服务。

卸载 App 会移除其私有数据；自选共享目录的文件保留。迁移完成后原位置保留副本，后续更新只写新位置。自选目录采用系统授权，不需要全盘存储权限；移动文件夹或撤销授权后需重新选择原位置恢复访问。[Android 文档存储说明](https://developer.android.com/training/data-storage/shared/documents-files)

请按需导出备份。ZIP 内是可直接解压的原文和 JSON；本版导入功能支持 PDF / DOCX / DOC，尚无 ZIP 一键恢复入口。没有自动云同步。

## 边界

旧图谱可以继续用于追问。需要新版紧凑大纲时，点击重新建立；升级本身不会自动发起模型请求。相比旧版，原文不再先识别结构后再次逐段长篇解读，减少重复输入和输出；实际节省比例与模型和论文长度有关。Android 前台 dataSync 服务持有 CPU 唤醒锁，独立 WebView 只执行建图核心，模型请求和存储由原生线程处理；Activity 关闭不主动销毁该任务。通知被拒绝不影响任务启动，但通知栏可能不显示进度。

系统强行停止、重启、网络错误或厂商省电策略仍可能中断进程；重开论文后显示中断/失败阶段，点击“继续建图”重放已完成批次，再请求未完成部分，不覆盖旧的完整图谱。强行结束前尚未返回的模型请求无法保存，其服务端用量仍可能产生；配置模型/地址变化后要求重新建图。Android 15 对 dataSync 有后台累计时限，本版响应系统超时并保留断点，单次运行也会在 5 小时 45 分停止；不是无限后台运行。[Android 后台服务时限](https://developer.android.com/develop/background-work/services/fgs/timeout)

段落问答仍属于当前阅读页面，退后台不保证其跨进程恢复；已保存问答保留，未完成的 pending 回答重开后标为中断。

单篇导入上限 60 MB，DOCX 展开总量上限 90 MB，精读文字上限 150 万字符。加密 PDF 需要先解密再导入；扫描页可阅读，但没有内置 OCR。双栏、公式和页眉可能影响文字和段落识别；图表视觉解释未实现。字符预算不是精确 token 预算，实际回答质量、费用与速度取决于所配模型。本地 HTTP 服务可填写手机可访问的局域网地址，手机的 localhost 指手机自身。

## 构建

项目使用 Node.js 24、JDK 17、Android SDK Platform 35 与 Build Tools 35.0.0。采用官方 AAPT2 / javac / D8 / zipalign / apksigner 打包，无 Gradle 依赖。

```powershell
npm ci
./scripts/setup-sdk.ps1
npm test
./scripts/native-check.ps1
./scripts/build-apk.ps1
node scripts/ui-check.mjs
node scripts/source-package.mjs
```

`scripts/build-apk.ps1` 默认 JDK 在 `D:/Program Files/Java/jdk-17.0.2`；可设置 `PAPER_JAVA_HOME` 指向其他 JDK 17。首次构建会在 `.signing/` 生成签名密钥，后续复用它以便覆盖升级。务必保留此目录用于后续发布；勿提交或公开密钥和密码。源码归档会排除该目录。界面测试使用电脑已安装的 Chrome，可按本机情况调整脚本路径。

Java 存储测试使用 org.json 20240303（仅测试），首次运行从 Maven Central 下载，脚本校验 SHA-256。Android APK 使用系统 org.json，不包含该测试 JAR 或测试替身。Lara Java SDK 1.12.0 与 Gson 2.11.0 由构建脚本从 Maven Central 下载并校验 SHA-256，然后一起编入 APK。
